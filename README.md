# VYTAL – AI-Powered Athlete Health Monitoring Platform

VYTAL is an intelligent athlete health monitoring and decision-support platform developed as a Computer Science graduation project at Umm Al-Qura University.

The platform combines Business Intelligence, physiological data analytics, evidence-based risk classification, and Generative AI to support athlete health monitoring and data-driven decision-making.

## Key Features

- Interactive athlete health monitoring dashboards
- Heart Rate, SpO₂, and Body Temperature analysis
- Evidence-based risk classification:
  - Green: Normal
  - Orange: Warning
  - Red: Critical
- Athlete-level physiological analysis
- Health trend monitoring
- Multi-player comparison
- Risk contribution analysis
- AI-generated athlete health interpretations
- Automated recommendation-oriented reports
